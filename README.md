# BeeECOM

BeeECOM is a full-featured dummy e-commerce reference application for validating and showcasing [BeeUI](https://github.com/beobungbu/BeeUI) across Web, iOS, and Android.

The program plan and work breakdown structure are tracked in [issue #1](https://github.com/beobungbu/BeeECOM/issues/1).

> Repository initialized for implementation. Product data and integrations are deterministic demo/simulator data only.
